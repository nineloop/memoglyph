# Memoglyph — noyau exécutable (API + moteurs STT).
#
# Manifeste de compatibilité pip. La source principale est pyproject.toml et
# tests/unit/test_dependency_manifest.py empêche les deux de diverger.
#
# Versions figées sur l'environnement VALIDÉ le 2026-07-19 (macOS arm64,
# CPython 3.11.14) : `make check` au vert et transcription complète — STT,
# diarisation, profil LLM — vérifiée de bout en bout.
#
# Elles décrivent le venv du projet (.venv, CPython 3.11.14 géré par uv), qui
# est désormais le SEUL interpréteur viable : l'environnement Anaconda a été
# désinstallé, et /usr/bin/python3 est un 3.9 sans nos dépendances. Les scripts
# de lancement et le Makefile détectent .venv/bin/python automatiquement.
#
# Prérequis NON pip : ffmpeg + ffprobe sur le PATH.
#   Ils viennent de Homebrew (/opt/homebrew/bin/ffmpeg). C'est ce qu'il faut :
#   torchcodec cherche ses `libav*` dans /opt/homebrew/opt/ffmpeg/lib. Chaque
#   version de torchcodec ne charge qu'une plage de FFmpeg : la 0.11 s'arrêtait
#   à FFmpeg 8 (`libavutil` 60) et la diarisation tombait dès que Homebrew
#   passait en 9 ; la 0.17 couvre FFmpeg 4 à 9 et retrouve le rpath Homebrew.
#   (Une note antérieure affirmait l'inverse — ffmpeg venait alors d'Anaconda,
#   depuis désinstallé. Elle était devenue fausse.)
